# research-paper-code

Code and documentation for Junaid Hassan's research papers. Each paper lives in its own folder, with the code used to produce its results and a paper-specific `README.md` explaining how to run it and how it maps to the paper.

## Papers

| Folder | Paper | Status | Links |
|---|---|---|---|
| [`lar-paper/`](./lar-paper) | Latent Attribution Regularization: Cross-Domain Attribution-Consistency Training for Stable NLP Explanations | Preprint published; under submission to a peer-reviewed journal | [Preprint (Research Square)](https://www.researchsquare.com/article/rs-10984984/v1) |

More folders will be added here as new papers are released.

## Structure

Each paper folder is self-contained:

```
<paper-folder>/
├── README.md      # paper summary, how to run the code, how outputs map to the paper's results
└── code.py         # the actual code used to produce the paper's results
```
